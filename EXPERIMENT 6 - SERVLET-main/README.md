# Servlet Web Application

This is a simple Java Servlet web application that I built while learning Java Servlets and Maven.

The project includes different Servlets, an authentication filter, an application listener, and a basic HTML page.

## Technologies Used

- Java
- Java Servlets
- Maven
- HTML
- Apache Tomcat

## Project Structure

The main Java files are inside:

`src/main/java/com/servlet/`

Some of the important classes are:

- `LoginServlet.java` – handles the login functionality
- `HomeServlet.java` – handles the home page
- `HelloServlet.java` – basic servlet example
- `AuthFilter.java` – used for authentication/filtering
- `AppListener.java` – application listener
- `Main.java` – main Java class

The HTML files are inside:

`src/main/webapp/`
